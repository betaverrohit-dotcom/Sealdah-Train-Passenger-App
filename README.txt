SEALDAH TRAIN SERVICE • PREMIUM APP
=====================================

Included:
- Premium responsive railway dashboard
- Login / Sign-up UI
- Passenger name / username search
- Private chat UI
- AI Bot chat UI
- Train search + station autocomplete
- PNR interface
- Timetable interface
- Leaflet live-route map interface
- Sealdah station database from the supplied app
- Supplied Sealdah Train Service logo

IMPORTANT:
The current login/chat layer is a front-end demo using browser localStorage.
For real users to find each other and chat across phones/devices, connect a shared
backend/database (Supabase, Firebase, or your own Node.js API).

The existing Render URL is kept in API_BASE in index.html. Its exact API routes
were not available from the supplied source, so no undocumented endpoints were invented.

Deployment:
Upload index.html and logo.png to the same web folder.
